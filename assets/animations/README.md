# Little Power Robot Animation

ALAN visual asset reference: **Little power robot** by **Md. Fazle Hasan**.

Source: https://lottiefiles.com/free-animation/little-power-robot-BtnSKUJQgN

License shown on the source page: **Lottie Simple License**.

## Planned ALAN uses

This animation is intended for:

1. **ALAN dashboard** — idle/assistant visual.
2. **Voice interaction** — show while ALAN is listening or processing.
3. **AI processing state** — animated loading/working indicator.
4. **Onboarding / first-run screen** — introduce ALAN's assistant identity.
5. **Project showcase** — visual element in `docs/alan-showcase.html`.

## Asset formats

The source page provides Lottie JSON, optimized Lottie JSON, dotLottie, SVG, GIF, MP4, WebM and MOV exports.

### Important

The repository should store the downloaded asset locally rather than depending on the LottieFiles webpage at runtime.

Recommended path after downloading:

```
assets/
└── animations/
    └── little-power-robot.json
```

For the desktop/web showcase, the local animation can then be loaded without requiring the LottieFiles website.
