# ALAN Contribution Plan

## Goal

Build the ALAN Personal AI project through genuine, useful development work rather than artificial or empty activity.

## Contribution rules

- Each contribution must represent a real project improvement, fix, test, documentation update, or feature.
- Changes must remain relevant to ALAN Personal AI.
- Important changes are recorded in `docs/CHANGELOG.md`.
- Commit messages describe the actual work performed.
- The ALAN application UI remains frozen unless explicitly requested.
- Project ownership remains documented as G.P. PRASANNA — Founder, Creator, and Main Developer.

## Milestone

Target: 100 genuine GitHub contributions through continued ALAN development.

The target is a development milestone, not a request to manufacture activity with meaningless commits.
